# Wild Explorer: Journal of Nature

An educational exploration game built in Unity with C#, where players walk through a nature environment, relax, and discover different animals.

## Features

- First-person exploration of an open natural world.
- Discover different animals around the map.
- Custom map and a menu built with SlimUI.
- Atmospheric visuals with URP and post-processing.

## Built with

Unity, C#, Universal Render Pipeline, and several nature and environment asset packs.

## Run

Open the project in Unity, open a scene from `Assets/Scenes/`, and press Play (or build it from File > Build Settings).
